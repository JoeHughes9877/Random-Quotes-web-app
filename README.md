# Random Quotes Web App

A simple web app that displays random quotes. Built to practice JavaScript fundamentals like DOM manipulation and event handling.

## Project Overview

This app shows a new random quote each time you click a button. It’s a straightforward project to get comfortable working with JavaScript on the web.

## Features

- Displays random quotes from a predefined list
- Updates quote on button click
- Clean and minimal design

## Purpose

To learn how to:

- Manipulate the DOM with JavaScript
- Handle user events
- Work with arrays and randomization

## How to Use

Open the `index.html` file in any modern web browser. Click the “New Quote” button to see a different quote.

## Technologies Used

- HTML
- CSS
- JavaScript
